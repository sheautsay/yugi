## 失敗與修正

| 失敗 | 根因 | 修正 |
|---|---|---|
| 編輯器 component「步驟」測試 | 測試只填摘要未填必填說明，儲存被正確擋下 | 測試補填說明，並新增上下移後順序與 ID 的明確斷言 |
| E2E 新增路線後看不到「已儲存（版本 1）」 | **程式缺陷**：新增後導向編輯網址會重建頁面，確認訊息遺失 | 以導覽 state 帶入訊息；重跑通過 |
| shell 路由 smoke test `/combos/x/edit` | 原預期為占位頁標題；真實編輯器對不存在的 ID 正確顯示「找不到 Combo」 | 更新該 smoke test 預期（與 `/decks/no-such-deck` 一致） |
