## 實作過程的失敗與修正

| 失敗 | 根因 | 修正 |
|---|---|---|
| `fullUrl` 測試 TypeError | 測試環境：fake-indexeddb 回傳的 Blob 無法在 Node 建立 object URL；同時發現**程式缺陷**：`return this.cachedUrl()` 未 `await`，錯誤會逃出 try | 程式加 `await`；該測試 shim `URL.createObjectURL`（真實瀏覽器由 E2E 驗證） |
| 同步寫入失敗未回滾（審查發現） | **程式缺陷**：catch 未 abort transaction，已送出的寫入可能自動 commit | 明確 `tx.abort()`；新增測試並以變異測試確認 |
| E2E 文字定位找不到元素（2 處） | 測試 regex 用 `^` 錨定，但模板文字前有空白 | 改用元素定位；預期不變 |
| E2E「全部卡片 99 張」、Skill 卡找不到 | 只同步 MD 卡池時本機沒有其他卡；**UX 缺口**：畫面未提示 | 新增提示與「下載全部遊戲王卡片資料」按鈕；測試先下載全部卡池 |
| E2E 儲存標註後看不到「已儲存」 | **程式缺陷**：同一張卡更新後被當成新卡，清除了確認訊息並重載圖片 | 只在換卡時重設 |
| 回歸：G9 兩項 | 設定頁多了「匯入卡片標註」檔案欄位，`input[type=file]` 不唯一 | 以「從備份檔還原…」標籤定位（CR-002 補充） |
| 回歸：N7 | 預設自動縮圖後，離線時會嘗試下載未快取縮圖 | 該測試開頭關閉自動縮圖（CR-002 補充），另新增 N15 驗證自動縮圖下的離線行為 |
| N15 等待逾時 | 離線時完整卡圖走重試／退避（1+2+4 秒） | 該斷言等待改 15 秒 |

## 限制

- **Master Duel 禁限表**：YGOPRODeck 不提供；畫面以 TCG／OCG 為參考，MD 禁限需使用者自行標註，只作提示。
- **繁體中文卡名／俗稱**：無可信公開來源；僅支援使用者輸入或匯入，備份會一併保存。
- 完整卡片資料約 24 MB；「全部卡片」需另外下載（多約 700 張）。
- 卡圖下載需以 `npm start` 啟動（圖片代理）；離線時完整卡圖約 7 秒後才顯示「無法下載」。
