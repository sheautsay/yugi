## 失敗與修正

| 失敗 | 根因 | 修正 |
|---|---|---|
| hand-page.spec 12 項皆停在「載入中」 | 測試輔助函式錯誤：元件建立後只先渲染標題，等待條件在載入開始前就成立 | 以暫時診斷檔確認後，等待條件改為「出現牌組內容」；診斷檔已刪除；斷言未改 |
| N3 測試設定失敗 | 測試在 `configureTestingModule` 前呼叫 `TestBed.inject` | 改在設定後注入；斷言未改 |
| 一次完整執行回報「Failed to start forks worker / Timeout waiting for worker」 | Vitest 工作程序啟動逾時（環境暫時性問題，無殘留測試程序） | 原命令重跑通過；之後完整測試套件亦通過 |
| E2E 草稿中「不符合（1）」 | 測試預期寫錯：該手牌下有 2 條不符合路線 | 預期改為 2（依實際資料計算，非放寬） |
