# G12 碼莉絲 Combo 人工實測檢核單

> G12：至少 1 條碼莉絲固定 Combo 經人工按原路線實測、留有 evidence；沒有實測就不能顯示 verified。  
> 目前狀態：**BLOCKED** — 需要使用者在 Master Duel 實際操作。開發者沒有遊戲環境，也**刻意沒有自行撰寫碼莉絲路線**（規格禁止以模型虛構路線代替實測）。

## 事前準備

- [ ] 在本工具「牌組」匯入**與遊戲中完全相同**的碼莉絲牌表（ydke:// 或 YDK），並按「下載缺少的卡片資料」，狀態為「可查詢」。
- [ ] 選定一條來源可靠的固定展開（影片或攻略），記下來源網址（YouTube／Bilibili／YGOPRODeck／MasterDuelMeta／官方資料庫）與時間點。
- [ ] 在「Combo 管理 → 新增 Combo」輸入該路線：名稱、系列 `Maliss`、前提（先後攻、空場、通常召喚、無干擾）、起手條件、每一步（動作、執行的卡、位置、目標、素材、代價、注意事項）、預計終場、來源。狀態先設「未驗證」。
  - 也可以把來源連結給開發者，由開發者轉錄成「未驗證」草稿，再由你核對。

## 實測

- [ ] 在 Master Duel 以符合該路線起手條件的手牌開局（例如反覆開局直到起手符合），對手不干擾。
- [ ] 開啟本工具該路線的「逐步教學」，**完全照步驟**操作，不自行改線。
- [ ] 全程錄影，或每一步截圖。
- [ ] 確認每一步的結果與工具內容一致，最後場面與「預計終場」一致。
  - 若任何一步不一致：修正路線內容後**重新實測**，不可直接標已驗證。

## 登錄驗證

- [ ] 在路線編輯器把狀態改為「已驗證」，填寫：
  - 實測日期（YYYY-MM-DD）
  - 驗證者
  - 驗證證據（例如：`錄影 maliss-route1-2026-10-xx.mp4 00:00–02:35`）
  - 實測使用的牌組（工具會記錄該牌表指紋；之後改動牌表，該路線會自動顯示為「未驗證」）
- [ ] 儲存後回到「起手查詢」，以同一牌組與符合的手牌查詢，確認該路線顯示「可用（已驗證）」。
