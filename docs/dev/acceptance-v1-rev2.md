## 2. 判定細則

### G17
1. 一鍵下載完整卡片文字資料；預設卡池為 Master Duel（`format=master duel`），設定可切換為全部卡片；卡片資料存 IndexedDB。
2. 同步後，搜尋與篩選不發出任何 API 請求。
3. 遠端 `database_version` 與本機記錄相同且卡池相同時，「更新」不重新下載卡片資料；另提供強制重新下載。本機記錄版本、最後更新時間、同步時間、筆數。
4. 下載失敗、回應格式錯誤或寫入失敗時：既有卡片資料、牌組、Combo 皆不變，版本記錄不更新，畫面顯示原因與下一步。
5. 同步不清除使用者自訂的繁中名稱、俗稱與 Master Duel 禁限標註；不改動牌組與 Combo。
6. 一次同步最多 2 個 API 請求（版本檢查 + 卡片資料），經統一 adapter、節流、重試／退避。

### G18
1. 搜尋支援：英文卡名（部分字串、不分大小寫）、卡片 ID、繁中名稱、俗稱（有資料時）。
2. 篩選：怪獸／魔法／陷阱、主牌組卡／額外牌組卡、系列、屬性、種族或魔陷類型、等級／階級；依目前卡池篩選。
3. 結果分頁，每頁固定張數，畫面一次只渲染一頁；15,000 張資料的篩選＋排序在單元測試中 < 500 ms。
4. 詳細資訊顯示卡圖、名稱、ID、類型、屬性／種族／等級／攻守、系列、效果文字、TCG／OCG 禁限參考。
5. 沒有繁中名稱時顯示英文名稱，程式不產生任何中文卡名；繁中名稱與俗稱只來自使用者輸入或匯入。

### G19
1. 卡片資料同步不下載任何圖片。
2. 縮圖只在卡片進入可視範圍時下載；同一張卡只下載一次並存 IndexedDB；重新載入後不再請求。
3. 完整卡圖只在開啟該卡詳細資訊時下載並快取。
4. 圖片請求經統一 adapter 節流（每秒 ≤ 10 次）；設定可關閉自動縮圖。
5. 下載失敗顯示卡名＋ID 框；外部來源中斷時已快取的圖片仍顯示。

### G20
1. 搜尋結果可用 ＋／− 增減牌組張數，張數與牌表檢核即時更新。
2. 同名卡（主＋額外＋備牌合計）最多 3 張：達上限時 ＋ 停用並說明。
3. 融合／同步／超量／連結（含靈擺版）自動加入額外牌組，其餘加入主牌組；Skill、Token 不可加入。
4. 禁限資訊獨立顯示為提示（TCG／OCG 為參考；Master Duel 由使用者自行標註），不改變既有牌表檢核與草稿判定。
5. 既有 YDK／YDKE 匯入與牌組資料格式相容；同步或更新卡片資料後，既有牌組內容不變。
6. `acceptance-v1.md`、`acceptance-v1-rev1.md` 既有測試全部回歸通過（CR-002 所列設定前提除外，斷言不改）。
