# YGO Combo 助手 V1 — 使用說明

本工具是《遊戲王 MASTER DUEL》玩家的**獨立**固定展開查詢與練習工具：不連接遊戲、不讀取遊戲資料、不自動操作。所有資料只存在你這台電腦的瀏覽器中。

## 1. 啟動

需要 Node.js 24 與 npm。在專案資料夾執行：

```bash
npm install
```

```bash
npm start
```

然後用瀏覽器開啟 <http://localhost:4200>。

- 卡圖下載需要透過 `npm start` 啟動的本機伺服器（內含卡圖代理）。
- 沒有網路時仍可開啟已存的牌組、Combo 與已下載的卡圖。

## 2. 匯入牌組

1. 到「牌組」頁，按「＋ 新增牌組」（還沒有任何牌組時表單直接顯示），在「匯入牌組」貼上 `ydke://…` 代碼或 YDK 內容（會自動判斷格式），或選擇 `.ydk` 檔，按「解析」。
2. 預覽會顯示主牌／額外／備牌張數；有不認得的卡時按「從 YGOPRODeck 下載缺少的卡片資料」。
3. 確認名稱後按「確認匯入」。取消不會改動任何資料。
4. 牌表檢核（主牌 40–60、額外 ≤15、同名 ≤3、所有卡都已識別）未通過的牌組只能是「草稿」，不能做起手查詢。禁限表不作為阻擋條件，請自行確認。

想先看看效果：到「Combo 管理」按「載入範例（Maliss）」，會加入一副範例牌組與 3 條「未驗證」的範例路線。

### 用 Master Duel 牌組代碼匯入（例如 `2962ut6`）

本工具不會自動讀取 KONAMI 官方網站（官方使用條款禁止未經同意的自動擷取），改用以下方式：

1. 在「匯入牌組」的「Master Duel 牌組代碼」輸入代碼（官方網頁複製教學預設收合，按「官方網頁複製教學」展開），按「在官方網站開啟」，會在新分頁開啟官方卡片資料庫的牌組搜尋。
2. 在官方頁點進牌組（頁面請切換為 English），從「Monster Cards」選取到最後一個表格，按 Ctrl+C。
3. 貼到「牌組代碼或 YDK 內容」，按「解析」。程式會核對各區合計張數，並用本機卡片資料庫把卡名對應成卡片 ID（請先下載完整卡片資料）。
4. 確認預覽無誤後按「確認匯入」。

官方頁搜尋不到牌組時，可能是代碼錯誤、牌組未公開或已被刪除；也可以改用 ydke:// 或 YDK 匯入。

在「編輯」頁可以調整張數、搜尋並加入卡片、下載此牌組卡圖、複製 ydke:// 代碼、下載牌組 JSON。

### 完整卡片資料庫與搜尋

1. 第一次使用時，在首頁「快速開始」的第 1 步（或牌組頁、起手查詢頁、AI 分析頁出現的提示）按「下載卡片資料」；也可以在「設定 → 完整卡片資料庫」按「下載／更新完整卡片資料」（Master Duel 卡池約 1.4 萬張、約 24 MB）。之後搜尋都在本機進行，不會再連線。
2. 再按一次會先檢查資料版本；版本相同就不重新下載（需要時可「強制重新下載」）。下載失敗不會影響原有資料。
3. 牌組編輯頁的「搜尋卡片並加入牌組」可用英文卡名、卡片 ID、你自己輸入的繁中名稱或俗稱搜尋，並依種類、主／額外牌組、系列、屬性、種族、等級篩選；結果分頁顯示。
4. 每張卡的「+1／−1」直接增減牌組張數：融合／同步／超量／連結怪獸自動放入額外牌組，其他放入主牌組；勾選「改為加入／移除備牌」則改動備牌。同名卡合計最多 3 張；Skill／Token 卡不能加入。
5. 「詳細」會顯示完整卡圖（第一次開啟時才下載）、英文效果、TCG／OCG 禁限（參考）；也可以輸入繁中名稱、俗稱與 Master Duel 禁限標註（資料來源沒有這些資料，本工具不會自行產生）。標註為限制卡等且張數超過時，牌組頁會出現提示，但不影響牌表檢核。
6. 縮圖在卡片出現在畫面上時才下載並存在本機；可在設定關閉自動縮圖。

## 3. 起手查詢

在牌組列表按「起手查詢」：

1. 選先攻（5 張）或後攻（6 張），以及情境（雙方空場、通常召喚權、假設不干擾）。
2. 取得手牌，三種方式擇一：
   - **手動選牌**：點主牌組卡池中的卡（數量徽標顯示剩餘張數，不會超過牌組張數）。
   - **隨機抽牌**：按「隨機抽 N 張」（不放回）；填「種子」可重現同一手牌。
   - **截圖辨識（實驗性）**：按「開啟截圖辨識」→ 上傳、拖放或 Ctrl+V 貼上起手截圖 → 用「框住整排手牌」或「逐張框選」框出每張手牌（可存成版型）→ 第一次使用先按「下載辨識用卡圖」→「開始辨識」→ 對「不確定／無法辨識」的卡選擇正確的卡 →「確認手牌並查詢」。截圖只在記憶體中處理，不儲存、不上傳。**辨識準確率尚未以實際截圖驗證，結果一律需由你確認。**
3. 選滿張數後顯示結果：
   - **可用（已驗證）**：符合條件且已在這份牌表上實測過。
   - **未驗證**：符合條件但尚未實測，僅供參考。
   - **不符合**：點開可看缺少什麼（例如缺卡、代價不足、主牌組剩餘不足、額外缺卡、先後攻不符）。
   - 沒有任何可用路線時顯示「沒有收錄符合目前起手的固定展開」——只代表資料庫中還沒有這樣的路線。

「可用」只代表符合該固定教學的前提，受干擾時不一定能走完。

## 4. 觀看展開

按「查看完整展開」：

- **圖像流程**：所有步驟依序排列（可切換垂直／水平、縮放），點任一步即設為目前步驟，可展開完整說明；最後是預計終場。
- **逐步教學**：一次一步，顯示「第 k / N 步」、卡圖、動作、位置、目標、素材、代價、結果、原因與注意事項；可用上一步／下一步、指定步驟、跳至終場、返回列表，或鍵盤 ← →。
- 兩種模式共用同一個目前步驟，來回切換不會跳步。按「下一步」只是閱讀導覽，不會對遊戲做任何事。

## 5. 管理 Combo

「Combo 管理」可新增、編輯、複製（複本為草稿）、刪除（需確認）、匯出／匯入 JSON。

- 匯入會先完整檢查，任何一條有錯就整批不寫入；原檔標示「已驗證」的路線匯入後一律改為「未驗證」。
- 只有附上**實測日期、驗證者、證據與實測所用牌組**，且有步驟的路線才能設為「已驗證」。已驗證路線若修改了條件或步驟，必須更新證據或改回未驗證。
- **分享碼**：每條 Combo 有「分享碼」按鈕，會產生一行 `YGOCOMBO1.…` 文字，可貼到聊天軟體；對方在「匯入 Combo」貼上（一行一個，可一次貼多個）就會走同樣的完整檢查與預覽，確認後才寫入，而且一律是「未驗證」。代碼被聊天軟體截斷或改過時會顯示「檢查碼不符」。
- 來源網址只接受 https 白名單網站，並在新分頁開啟。

如何完成第一條碼莉絲實測，請見 [dev/g12-maliss-verification-checklist.md](dev/g12-maliss-verification-checklist.md)。

### 中文名稱檔格式

「設定 → 卡名顯示與中文名稱資料」可匯入你整理的 JSON 陣列檔。每筆含整數 `cardId`、`translationSource`（來源說明）、`translationStatus`（`official`、`community` 或 `provisional`），以及 `nameZhTw` 或 `nameZhCn`；可選填 `aliases`。整份檔案先檢查，只要有一筆錯誤就整份不匯入；你在卡片詳細資訊中的修正不會被匯入覆蓋。

## 5.5 先攻 FTK 牌組（進階）

一副牌靠抽牌與效果傷害在先攻第一回合擊殺（例如 Banquet FTK），可以在「編輯牌組」勾選「這是先攻 FTK 牌組」。之後：

- **AI 展開分析**改用另一套指示（一次請求），要求 AI 輸出「依抽到的卡分支」的計畫。抽牌、翻開牌組頂這類結果未知的步驟只記錄張數，**不能指定抽到哪張卡**；抽到什麼要用「分支」表達（抽到 A 或 B → 分支 1；否則 → 分支 2），每個抽牌步驟都要有「否則」分支。
- **傷害由本機算，不採信 AI 的數字**：依卡片規則表與步驟中的卡片移動計算（例如「Banquet of Millions」每從額外牌組除外一張，對手就多一張除外；「D.D. Dynamite」每張除外的卡造成 300 傷害）；LP 代價與對手回復也會計入。標為成功但沒有把對手 LP 打到 0 的分支，檢查不會通過。這回合蓋放的陷阱必須有「陷阱戲法」「陷阱愛好者」這類效果允許才能在蓋放的回合發動。
- **成功率由本機精確計算**（超幾何分布，沿分支樹加總），顯示在分析結果與實戰模式。結果依成功率排序。
- **實戰模式**：輸入起手後依成功率列出計畫；選一個計畫逐步走，遇到抽牌步驟時輸入實際抽到的卡，程式用剩餘牌組重算成功率、指出要走的分支，並顯示對手剩餘 LP。

限制：假設無干擾（對手的手坑可能直接讓計畫失敗，成功率不包含這個風險）；假設對手額外牌組有 15 張可被除外的卡；沒有規則引擎，無法確認效果在當下是否真的能發動；「Chicken Game」的「LP 最低者不受傷害」沒有模擬；分支樹太大時會顯示「無法計算」而不是估計。這些計畫都需要你在遊戲中實測。

## 5.6 實戰模式：一鍵截圖辨識（Windows 桌面版）

先到「設定 → 實戰模式」啟用實戰模式。

1. Master Duel 請用**視窗模式**（獨佔全螢幕時無法截取）。
2. 起手後按快捷鍵（預設 `Ctrl+Shift+Space`，可在設定修改），或在實戰模式頁按「截取遊戲畫面辨識」。程式只截取一次 Master Duel 視窗，截圖只在記憶體中處理，不會儲存。
3. **第一次**會請你在截圖上框一次手牌，按「記住為遊戲視窗的手牌位置」。先攻 5 張、後攻 6 張各記一次；位置以視窗的相對座標儲存，移動或等比例縮放視窗後仍可使用。視窗長寬比改變時會請你重新框選。
4. 之後按快捷鍵就會直接辨識：每張都有高信心時立刻列出建議展開；有不確定的卡時，只需在下方點選正確的卡。

在設定中可以清除已記住的手牌位置。不讀取遊戲記憶體、不操作遊戲；KONAMI 的使用條款對第三方輔助工具沒有明確界線，是否使用由你自行判斷。

## 6. 備份與還原

資料存在瀏覽器的 IndexedDB，清除瀏覽器資料就會消失。請在「設定」定期「匯出完整備份（JSON）」。

還原時會先預覽；ID 相同但內容不同時可選「保留兩者／覆蓋／略過」，同名資料會加上「（還原）」。備份不含卡片資料與卡圖，還原後請到牌組編輯頁重新下載。

## 7. 已知限制

- 卡名為英文（尚無可信的繁體中文卡名來源）。
- 截圖辨識使用標準卡框的插畫位置，靈擺卡與異圖可能較常被判為不確定；Master Duel 實際截圖的準確率尚未驗證。
- 不做即時牌局追蹤、自動出牌或動態改線；不讀取 Steam／Master Duel 的任何資料。
