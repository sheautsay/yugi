## 失敗與修正（皆已重跑通過）

| 失敗 | 根因 | 修正 |
|---|---|---|
| card-api.spec 圖片測試 | 測試 fixture：jsdom Blob 交給 Node `Response` 時遺失 content-type | fixture 改以 header 指定 `image/jpeg`；斷言未改 |
| import panel「下載後查無 6 個 ID」 | 測試等待過短（固定 5 tick），fake IndexedDB 多筆寫入未完成 | 改為輪詢直到文字出現；斷言未改 |
| E2E 編輯頁「儲存」無法點擊 | 測試情境錯：−1 再 +1 回到原狀，按鈕本應停用 | 情境改為真正的淨變更，並新增「回到原狀時儲存停用」斷言 |
| E2E 卡圖下載逾時 | 33 張 × ≥250 ms 節流需約 8 秒；且畫面無進度提示 | **程式修正**：新增「正在下載 N 張卡圖…」進度訊息；該斷言等待改 30 秒 |
| E2E 離線重新整理失敗 | `setOffline` 連 localhost 一起斷，不符「網路斷、本機伺服器仍在」的實際情境 | 改為攔截所有外部卡片來源請求並驗證 0 次外部請求 |
| E2E 文字定位多重匹配（2 處） | 新增狀態訊息／fallback 卡名造成重複文字 | 改用精確或 `.first()` 定位 |

## 限制

- 卡圖下載依賴 `npm start`（`ng serve` 的 `/ygo-images` 代理）；以其他靜態伺服器提供 build 時，卡圖下載會失敗並顯示原因，其餘功能不受影響。
- 繁體中文卡名：無可信來源，顯示英文卡名（規格 F10）。
